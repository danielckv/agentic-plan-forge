# Security Policy

## Supported Versions

Agentic Plan Forge is pre-1.0. Only the latest state of the `main` branch receives security fixes; no released versions are maintained.

| Version | Supported |
| ------- | --------- |
| latest `main` | Yes |
| anything else | No |

## Reporting a Vulnerability

Report vulnerabilities privately through GitHub's private vulnerability reporting:

<https://github.com/danielckv/agentic-plan-forge/security/advisories/new>

If that form is unavailable, email <danielckv@gmail.com> with the subject prefix `SECURITY:`.

Do not open public issues, pull requests, or discussions for security vulnerabilities.

## What to Include

- The affected version or commit of the repository.
- Steps to reproduce the issue, including any relevant input or configuration.
- The impact of the vulnerability and, if possible, an assessment of its severity.

## Response Targets

This is a single-maintainer, volunteer project, so no response time is guaranteed; security reports are prioritised over other issues, but still handled on a best-effort basis.

- Acknowledgement is aimed for within about a week.
- Triage happens as soon as possible after acknowledgement.
- After a fix is available, disclosure is coordinated with the reporter before any public advisory is published.
