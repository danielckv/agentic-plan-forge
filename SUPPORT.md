# Support

## Bugs and Feature Requests

Use GitHub Issues for bug reports and feature requests:

<https://github.com/danielckv/agentic-plan-forge/issues/new/choose>

Pick the issue template that matches your request and fill it in as completely as you can. General questions are not currently supported through the issue tracker.

## Security Issues

Do not report security vulnerabilities through public issues. See [SECURITY.md](SECURITY.md) for the private reporting process.

## Commercial Support

There is no paid support or service-level agreement for this project. Responses are provided on a best-effort basis by volunteers.
